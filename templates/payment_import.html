Accepted Fee Sheet Column Structure

The importer automatically parses spreadsheets formatted with the following columns:

Flexible Parser
Column Name Accepted Headers Valid Values Description
student_id (Required) student_id, id, reg no, student no Integer ID (e.g., 6, 19) Unique student identifier matching registered user records.
status (Required) status, payment status, paid, fee status Paid, Unpaid, P, 1, 0, Yes, No Payment status. Only rows marked Paid will create financial ledger entries.
amount (Optional) amount, monthly fee, fee, payment amount Decimal number (e.g., 2500.00) Collected amount in LKR. Defaults to course tuition fee if blank or omitted.
period (Optional) period, billing month, month YYYY-MM (e.g. 2026-10) or text (e.g. October 2026) Billing period. Defaults to selected billing month if omitted.
payment_date (Optional) payment_date, date, paid date YYYY-MM-DD format Transaction date. Defaults to selected payment date if omitted.
student_name (Optional) student_name, name Text string Used for human-readable verification on paper sheets.
