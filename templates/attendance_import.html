Accepted Sheet Column Structure

The importer automatically parses spreadsheets formatted with the following columns:

Flexible Parser
Column Name Accepted Headers Valid Values Description
student_id (Required) student_id, id, reg no Integer ID (e.g., 6, 19) Unique student identifier matching user records.
status (Required) status, attendance, present Present, Absent, P, A, 1, 0 Case-insensitive attendance status. Defaults to Present if omitted.
student_name (Optional) student_name, name Text string Used for human-readable verification on paper sheets.
date (Optional) date, session_date YYYY-MM-DD format Allows single spreadsheet to import multiple dates if provided per row.
