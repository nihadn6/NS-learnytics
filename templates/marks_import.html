Supported Spreadsheet Column Formats (Optional Reference) View Column Guide ↓

The importer automatically recognizes spreadsheets containing the following standard headers:

Column Name Accepted Headers Valid Values Description
student_id (Required) student_id, id, reg no, student no Integer ID (e.g. 5, 19) Unique student identifier matching user accounts.
marks_obtained (Required) marks_obtained, marks, score, result Number (e.g. 85, 92.5) Student score. Rows with blank or non-numeric scores are skipped.
test_name (Optional) test_name, assessment, exam, title Text string Defaults to form assessment title if omitted in the file.
max_marks (Optional) max_marks, max, total_marks Number (e.g. 100) Assessment total scale. Defaults to form value if omitted.
date_recorded (Optional) date_recorded, date, exam_date YYYY-MM-DD Examination date. Defaults to selected date if omitted.
student_name (Optional) student_name, name Text string Used for human-readable verification on paper marksheets.
